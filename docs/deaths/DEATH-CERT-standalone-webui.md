# 死亡证明 · 独立 WebUI（同构版跑通即脱落）

| 字段 | 内容 |
|---|---|
| id | `standalone-webui` |
| 出生 | 合拢期夹具：为了让生态在**没有真正前端**时也能看事件，做的一份独立 WebUI |
| 触发条件（自己那条 revisit） | 「同构版跑通即脱落」——同构版指：AG-UI additive 出口落地后，页面可由**标准事件 + metadata** 渲染，不再需要专用前端 |
| 死因 | 它的存在理由是"补上没有前端"，而 AG-UI 出口落地后，这个理由消失 ⇒ **理由消失即死**，不是"没时间维护" |
| 腐殖质（保留，不删） | ① 事件渲染的字段选择经验（哪几个键真被用到）② 布局默认值（栏宽/展开的初始值）③ 证轨只读的交互约束（不可点、不可授权） |
| 受体（谁吸收） | L1/L2/L3 三层（manifest 侧栏 / 选中才开的 additive 出口 / 可删本地偏好）；腐殖质进 L3 默认值 |
| 判据（怎么确认它真死了） | 删掉 `web/` 后：AG-UI 事件仍能被任意合规客户端渲染出同样信息；TUI 不受影响；`git grep -l 'standalone-webui'` 只命中本证明与坐标 |
| 不做什么 | **不删历史**（代码留在 git 历史里）；不写墓碑进账本；不伪装成"延期豁免" |
| 落款 | 2026-11-05 · 由死亡证明覆盖，不靠记忆 |
