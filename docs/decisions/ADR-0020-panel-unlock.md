# ADR-0020: 面板的解锁（密码）—— 草案，未冻结

- **状态**: **Draft · 未冻结**（Proposed 的前一档：问题与选项已固定，选择未定）。本文件固定的是**问题、约束与选项**，不是选择。
  用户原话：「密码解锁」；并明确要求「先做成 ADR，并先不冻结」。
- **日期**: 2026-09-16
- **上游**: ADR-0015（面板视图）、ADR-0017（资产语言）、ADR-0033（白盒窗口）

## 1. 为什么现在只写到这里

「密码解锁」目前是**一句诉求，不是一条需求**：保护对象、威胁模型、凭据来源都还没定。
把未澄清的需求冻结成决策，就是**用确定性覆盖未知**——本仓已经因为「看起来完整的数字其实不可信」
付过代价（导出里三个 turn 同报 4,398）。所以本 ADR 先把**必须回答的问题**和**已经明确的约束**
写下来，等澄清后再定案。

## 2. 已知的事实（不是推断）

- 面板默认只 **bind 127.0.0.1**（`start-panel.sh` 的端口参数），**不对外监听**。
- 面板能读到的**敏感物**：经历事件流（含 `assistant/think` 全文与用户输入）、
  Tuck 审计链、生态状态、供应商池与当前模型、以及**导出的 Markdown 文档**。
- 凭据**现在不在面板里**：Tuck 的 key 由 Tuck 自己的配置持有；面板通过 `/api/*` 代理读。
- 已有的事实来源惯例：**一个事实一个来源**（本仓铁律）。凭据一旦在面板里再存一份，
  就出现第二个真相源 —— 这是本 ADR 最需要防的形态。

## 3. 候选选项（按「零硬编码 / 极致解耦 / 按需加载」排）

| # | 选项 | 代价 | 与既有原则的冲突 |
|---|---|---|---|
| A | **启动口令**：进程启动时读环境变量或工作区文件，未提供则不启动 | 口令进 shell 历史/进程环境 | 无（凭据不进资产） |
| B | **页面口令**：前端存口令哈希，解锁后渲染 | 哈希进资产 ⇒ **0 硬编码被破坏** | ❌ 除非哈希来自服务端注入 |
| C | **只锁敏感面**：整站不锁，`think` 全文 / 审计链 / 导出需解锁 | 需要在每条读取路径上判定 | 判定点若分散 ⇒ **一事实多来源** |
| D | **不引入口令**：维持「仅本机可达」并把它写成**显式假设**（含非回环访问的显式拒绝） | 同机他人可读 | 最省，但没回答诉求 |
| E | **服务端会话**：口令校验在 panel 进程内，凭据来自环境；解锁态放签名 cookie | 需要一个会话概念（面板目前无状态） | 与「确定性优先」尚需对齐（会话依赖时钟） |

**倾向（未定案）**：**A + C**。理由：口令不进资产（A 满足零硬编码），
锁定面按「谁在什么条件下能读什么」集中在一处判定（C 可满足一事实一来源），
且不需要面板引入会话状态。

## 4. 冻结前必须回答的问题（每一条都会改变结论）

1. **保护对象**：整站？还是 `think` 全文 / 审计链 / **导出的文件**？
   （导出的 Markdown 是本轮新增的资产：**它出了面板就不再受任何锁约束** —— 这条最容易被忽略。）
2. **威胁模型**：同机他人 / 局域网 / 云端备份 / 浏览器历史？
   不同答案对应完全不同的方案（D 只对第一种成立）。
3. **凭据来源**：环境变量 / 系统钥匙串 / 工作区文件（且该文件**必须在 git 之外**）？
4. **忘记口令的行为**：拒绝服务，还是提供重置（重置 = 一条旁路，必须同样显式）。
5. **解锁态存哪**：仅内存（刷新即失效）/ 会话 cookie / 每次都问？
6. **失败要可分辨**：错口令与「未配置口令」必须是**两个可区分的状态**，
   不能都渲染成同一个「拒绝」——那是「恒 `—` 的占位槽位」的同类违规。

## 5. 本 ADR **不做**的事

- 不改任何资产、不加任何界面、不动 `prove_track.*`。
- 不引入后端会话、不改 `server.rs` 的路由表。
- **不冻结**：第 4 节的六条回答之前，任何实现都算抢跑。

## 6. 与既有决策的关系

- **不违反** ADR-0016（资产解耦）与 ADR-0018（一笔 tape 多投影）：本决策只决定
  「谁可以读」，不决定「怎么读」。
- **约束** 导出（本轮新增）：一旦导出文件落盘，它就脱离了面板的锁 —— 若保护对象含导出物，
  决策必须覆盖**落盘之后**的形态（例如导出前要求解锁，或导出物标注来源与时刻）。
