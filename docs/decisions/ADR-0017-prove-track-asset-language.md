# ADR-0017: 证轨资产语言统一（源码与界面文案一律英文）

- **状态**: Accepted
- **日期**: 2026-09-14
- **关联**: ADR-0015（D8 资产化拼装 / D11 组件资产层）、ADR-0016（证轨资产解耦，确立五资产边界）、ADR-0038（上游计量捕获，本 ADR 的触发面）、ADR-0037（术语更名 Engram → ProveTrack）、`docs/DNA.md` 铁律 2

## 1. 背景与问题

用户长期约定「**源代码与代码注释一律英文**」，但默认**只对新增/改动代码生效，存量不擅自 retrofit**。

2026-09-14 对 `prove_track.data.js` 用户给出了更明确的一档口径：**整个文件改英文，含界面文案**（不止注释）。该裁决已落地（提交 `0f4c7d0`）：`STATUS.t` 产出 `success / failure / pending / done`、`SCHEMA_NOTE` 的 11 条事件说明、`summarize` / `resultOf` 的全部产出文案均为英文。

但该裁决**只落到了 data.js**。同轮核查发现证轨五资产随即陷入**语言不一致**：

| 资产 | 改前状态 |
|---|---|
| `prove_track.data.js` | 全英文（含界面文案） |
| `prove_track.view.js` | 注释 + 界面文案均中文（`LLM 耗时` / `缓存命中` / `输入 TOK` / `类型` / `状态` / `占全程` …） |
| `prove_track.js` | 注释 + 界面文案均中文（`全部折叠轮次` / `等宽` / `实际耗时` …） |
| `prove_track.html` | 注释 + 骨架文案均中文（`等宽` / `类型` / `摘要` / `状态` / `耗时` / `描边 = 失败` …） |
| `prove_track.css` | 注释中文（声明本身无文案） |

后果是**同一屏内中英混排**：事件表的状态列渲染 data.js 产出的英文 `success`，而紧邻的统计栏标签是「缓存命中」；按钮由 html 提供中文初值、又被 js 改写成中文。混排比全中文更差——同一界面的两个投影（数据层产出 vs 视图层标签）用两套词汇，读者需要维护两套映射，且没有一处能作为「证轨该用什么语言」的权威。

## 2. 决策

### D1: 范围 = 证轨五资产，一次全量对齐

`prove_track.css` / `prove_track.html` / `prove_track.data.js` / `prove_track.view.js` / `prove_track.js` 五个资产一次改齐。**不扩散**到 `base.html`（应用外壳）、`session.html` / `script.html` / `flows.html`（其他视图）——它们的中文是产品既定语言，另行裁决。

证轨是本轮唯一被点名的界面面，五资产是它的最小自洽单元。

### D2: 界面文案一并英文化（不只注释）

按用户 2026-09-14 对 data.js 的裁决口径统一：注释与**界面文案**同档处理。

理由：若只改注释、文案留中文，则 data.js 的英文产出与 view.js 的中文标签仍混排（D1 要消除的正是这个）；注释与文案分档会让「一个资产内两种语言规则」成为新的一致性债。

### D3: 向数据层对齐，不回退数据层

data.js 的英文产出（`STATUS.t` / `SCHEMA_NOTE` / `summarize` / `resultOf`）是**先例**，保持不动；改的是其余四个资产向它对齐。回退 data.js 等于推翻已提交的裁决，且方向与用户要求相反。

### D4: 逐条精确替换 + 每对断言恰好命中一次

转换以「原串 → 新串」的**逐对精确替换**执行，每一对在落盘前断言**恰好命中一次**（0 次 = 目标已变或写错，>1 次 = 目标不唯一），全部通过后才写文件。

拒绝用 CJK 正则批量替换：正则会误伤代码与既有英文注释中的中文标点/符号（如全角括号、`——`、`·`），且无法逐条证伪「这一处确实改了、且只改了这一次」。

### D5: 术语对照表（跨资产用词一致）

| 中文 | 英文 | 出现处 |
|---|---|---|
| 证轨 / ProveTrack | ProveTrack | 五资产文件头 |
| 轮次 | turn | `Turn N` / `Collapse all turns` |
| 事件表 / 摘要 / 状态 / 耗时 | event table / summary / status / duration | 表头 + 检查器 |
| 缓存命中 / 输入 TOK | cache hit / input TOK | 统计栏（与 data.js 派生字段 `cached` / `input` 同词根） |
| 重放轨迹 / 重放中 | Replay / Replaying | 按钮两态 |
| 等宽 / 实际耗时 | equal width / actual time | 时长模式两态 |
| 描边 / 脉冲 | outline / pulse | 图例 |
| 连续卡住 | stuck streak | 卡住判定 |
| 占全程 | share | 检查器 |
| 检查器 | inspector | 右侧抽屉 |

### D6: 不动外部设计工具注入的 `data-page-node-id`

`prove_track.html` 工作区版本带有一批 `data-page-node-id="…"` 属性（外部设计工具注入，非本仓工作产物）。本 ADR **不**增删这些属性——它们与本决策无关，属独立议题。

### D7: 本次不做

- 不改任何行为、不改任何视觉、不改任何线协议或 API 契约——纯语言替换，`git diff` 增删行数对称。
- 不 retrofit `base.html` / `session.html` / `script.html` / `flows.html` 与 README / ADR 正文（文档按既有惯例保持中文）。
- 不引入 i18n 框架 / 语言包 / 构建步骤——本决策是「选一种语言」，不是「支持多语言」。

## 3. 备选方案与拒绝理由

| 备选 | 拒绝理由 |
|---|---|
| 只改 `prove_track.view.js`（用户点名的文件） | 混排未消除——html 骨架与 ctrl 的按钮文案仍中文，点一下按钮就在英文视图里弹出中文标签 |
| 只改注释，界面文案保留中文 | 与 2026-09-14 对 data.js 的裁决口径冲突；且 data.js 已产出英文标签，会形成「数据层英文 / 视图层中文」的新混排 |
| 把 data.js 回退成中文以求一致 | 推翻已提交的裁决（提交 `0f4c7d0`），且方向与用户要求相反 |
| 全仓（含 `base.html` / 其他视图）一并英文化 | 超出被点名的范围；外壳与其他视图的中文是产品既定语言，应另行裁决（D1） |
| 用 CJK 正则批量替换 | 会误伤代码与既有英文注释中的中文标点；且无法逐条证伪（D4） |
| 引入 i18n 语言包 | 本决策只选一种语言，不引入第二套语言与运行时查表；违反零构建依赖 |

## 4. 后果

- **正面**：证轨五资产语言自洽；data.js 的英文产出不再被视图层中文包围；后续新增代码有明确的英文先例；**CJK 扫描（`[\u4e00-\u9fff]`）可作为回归网**——证轨资产的 CJK 计数应恒为 0。
- **代价**：证轨视图的界面文案变英文，与 Cellrix 应用外壳及其他视图（中文）形成**跨视图**语言差异。这是 D1 刻意的边界，不是遗漏：证轨被单独点名，其余视图待裁决。
- **不变式（验收条件）**：
  1. 证轨五资产 CJK 行计数 = **0**；
  2. `node --check` 三个 JS 资产通过；
  3. `cargo test --no-fail-fast` 全绿 —— `main.rs` 的 `assert!(html.contains("证轨 ProveTrack"))` 仍成立（该串由 `base.html` 提供，不在本次范围）；
  4. 数据层回放断言全绿（计量口径未变）；
  5. 对外接口名 `window.__proveTrackLoad` / `window.__proveTrackClear` 不变（ADR-0016 D2 的契约不受影响）；
  6. 装配链的既有 DOM 断言（`id="eTblVp"` / `id="eLaneInput"` / `id="eInsp"` 等）继续通过。
