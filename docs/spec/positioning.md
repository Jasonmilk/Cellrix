## 一、Helix 生态中的位置

Cellrix 是 Helix 生态的**皮肤**——语义投影终端。

| 组件 | 职责 | Cellrix 的关系 |
|---|---|---|
| Helix-Mind | 思考、认知工艺 | Cellrix 展示 Mind 的认知输出 |
| Anaphase-Helix | 编排、调度 | Cellrix 作为 Anaphase 的客户端 |
| Helix-Tentacle | 工具执行 | Cellrix 展示工具执行结果 |
| Tuck | 安全闸门 | Cellrix 展示 Tuck 的审计和决策 |
| CI-144 | 通信协议 | Cellrix 是 CI-144 的参考实现 |
| Callosum | 上下文压缩 | Cellrix 展示压缩后的语义快照 |
| FlowModus | 缓存路由 | Cellrix 展示路由状态 |
| Lumtract | 设计血统 | Cellrix 遵循 Lumtract 设计语言 |

## 二、独立价值

Cellrix 不属于任何生态，但可以无缝融入任何生态。

### 2.1 碳硅同构
- 同一帧同时服务人类视觉和 AI 语义
- 人类看到美丽的视觉布局
- AI 无需 OCR 即可理解和交互

### 2.2 协议标准化
- CI-144 协议家族的官方参考实现
- CIN7/CIC13/CIB19 标准化
- 任何兼容 CI-144 的智能体都可以连接

### 2.3 多客户端复用
- Wayland 风格 UDS 多路复用
- 单实例服务多个智能体
- 后台客户端零堆分配

### 2.4 极致节能
- 19 秒质数心跳（防止共振）
- 40 秒超时（自动释放）
- 后台标签窥探（零堆分配）

## 四、适用场景

### 4.1 AI 助手界面
- AI 智能体的原生交互界面
- 无需 OCR 即可理解屏幕内容
- 确定性语义节点支持精确交互

### 4.2 多智能体协作
- 多个 AI 智能体共享一个终端
- Wayland 风格多路复用
- 焦点管理防止干扰

### 4.3 服务器管理
- 低资源占用的服务器管理界面
- 远程访问（TCP/UDS）
- 审计日志和安全事件展示

### 4.4 嵌入式设备
- 资源受限设备的 UI 运行时
- 256 节点硬限制防止 OOM
- WASM 兼容

---

## 五、不适用场景

- 复杂图形渲染（游戏、视频编辑）→ 使用 Web UI 或原生 GUI
- 多人实时协作（文档编辑）→ 使用 Web 应用
- 移动设备界面 → 使用原生移动 UI 框架
